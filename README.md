# Kahve Tembellik Makinesi

## Giriş

Bu proje, insanlık tarihinin en önemli yazılım çalışmalarından biridir. Tembellik, modern çağın en büyük sorunu olarak kabul edilmektedir. Bu yazılım, tembelliği bir bilim dalı haline getirerek, kullanıcıların kahve tüketimini optimize eder ve tüm görevleri "yarın"a erteleme yeteneğini maksimize eder.

**Uyarı:** Bu yazılım gerçektir. Gerçekten çalışır. Gerçekten tembeldir.

## Özellikler

- Kahve sayısını takip eder (hayali kahve bile sayar)
- Her görevi en az 24 saat erteler
- Sonsuz döngüde "Yarın yaparım" der
- Kullanıcıyı motive etmez, aksine tembelliğe teşvik eder
- %100 Python, %200 absürt

## Kurulum

```bash
pip install -r requirements.txt  # hiçbir şey yok ama olsun
python tembellik.py
```

## Kullanım

Programı çalıştırın. Size kaç kahve içtiğinizi soracak. Sonra sonsuza kadar bekleyeceksiniz. Çünkü yarın.

## Katkıda Bulunma

Katkıda bulunmayın. Yarın yapın.
